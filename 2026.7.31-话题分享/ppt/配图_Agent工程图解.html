外行也能懂的 AI Agent 黑话（配套分享稿.md · 第 2 期 2026-07-31）

① 五层架构：从里到外，每层多管一圈

Prompt → Context → Harness → Loop → Graph，越往外越"管全局"。Graph 包住下面四层，不替代它们。

记忆点：Prompt 管"一次怎么问"，Context 管"看什么"，Harness 管"环境"，Loop 管"单 Agent 自转"，Graph 管"一群怎么协作"。

② Harness = 套在模型外的"马具 / 工作环境"

模型是绝顶聪明但没边界的大脑；Harness 是缰绳 + 马鞍 + 围栏 + 路——让它能安全干活。

公式：agent = model + harness。"模型装着智能，Harness 是让智能有用的系统。"

③ Agent Loop = 一个 Agent 自己干活的"死循环"

丢一个目标进去，它自己看→想→干→验，没好就重来，直到合格或停等人。

真实例子：客服群有人报 BUG → Agent 自动监听、识别关键词、建任务、查日志、低风险自改上线、高风险转人工。全程无人盯。

④ Graph = 一群节点分工（组织架构图）

Node=干活的岗位（只干一件事），Edge=数据从谁流到谁。执行顺序 ≠ 数据依赖，能并行的就并行。

对比 Loop：Loop 是一个人包揽所有事反复打磨；Graph 是组团队，能并行的并行（如"查天气"不必等"总结文件"）。每个节点本身仍是个 Loop。
